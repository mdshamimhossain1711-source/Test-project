# Test-project

A Node.js application written in TypeScript and built with Next.js.

## Tech stack

- **Runtime:** Node.js
- **Language:** TypeScript
- **Framework:** Next.js (App Router, React Server Components)
- **Package manager:** npm

## Getting started

### Requirements

- Node.js 20 or later
- npm

### Install

```bash
npm install
```

### Run

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Scripts

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Next.js development server |
| `npm run build` | Create a production build |
| `npm start` | Run the production server |
| `npm run lint` | Run the linter |
